# Maaz Ahmed — Birthday Website

Files:
- index.html — complete website
- maaz-photo.jpg — portrait cropped from the uploaded reference screenshot

To use your own photos:
1. Replace maaz-photo.jpg with your preferred photo.
2. For multiple carousel photos, add photo2.jpg/photo3.jpg and edit the three slide image names in index.html.

The page includes:
- neon beating-heart splash screen
- dark purple/pink birthday-card theme
- animated cake + candle
- automatic candle blow-out after 5 seconds
- custom typewriter birthday message
- live digital clock
- automatic photo/caption carousel
- mobile responsive layout

Open index.html in Chrome to preview.
